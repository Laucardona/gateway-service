# Gateway Service — Prueba Tecnica Carvajal

API Gateway centralizado que enruta las peticiones hacia los microservicios
del proyecto y valida la autenticacion mediante JWT.

## Tecnologias
- Java 21
- Spring Boot 4.1.1
- Spring Cloud Gateway (Server WebMVC)
- JJWT (JSON Web Token)
